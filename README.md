# Création d’un système d’emploi du temps intelligent

Gérer un emploi du temps universitaire peut vite devenir un casse-tête : modifications de dernière minute, conflits de créneaux, répartition inégale des cours… Pour répondre à ces défis, j’ai développé un système intelligent de gestion d’emplois du temps, capable de s’adapter aux changements et d’optimiser l’organisation des cours.

## 🔍 Structurer et modéliser les données
J’ai commencé par collecter et nettoyer les données des cours d’un semestre, en utilisant Python pour identifier les incohérences et structurer les informations de manière optimale.
​
## 🗄 Création et gestion des bases de données
Grâce à SQL, j’ai conçu une base de données relationnelle permettant de stocker efficacement les informations sur les enseignants, les salles, les créneaux horaires et les modifications éventuelles.
​
## 💻 Développement d’une interface web interactive
Pour rendre la gestion plus fluide, j’ai développé un site web dynamique avec Flask (Python), JavaScript, HTML et CSS. Cette plateforme permet aux utilisateurs de consulter et modifier les emplois du temps en temps réel, tout en mettant automatiquement à jour la base de données.
